# SignalSlinger 2.0.7

SignalSlinger 2.0.7 adds persistent RF frequency calibration and a dedicated
calibration carrier for accurate alignment of individual transmitters.

## User-visible changes

- `FRE CF frequency` selects and immediately keys a temporary calibration
  carrier. Whole-number frequencies use kHz and decimal frequencies use MHz;
  the supported range is 8 kHz through 160 MHz. This carrier frequency is
  volatile and returns to the 3.600 MHz default after restart.
- `FRE C offset` applies an offset in Hz, immediately retunes the active
  carrier, and saves the corresponding oscillator correction in EEPROM. The
  correction is restored automatically after every restart.
- `FRE C` reports the applied offset and the stored parts-per-billion
  correction. `FRE C X`, or any physical button press, exits calibration mode
  without changing the last saved correction.

## Stability and reliability

- Calibration changes are transactional: RF is powered and retuned before a
  correction is saved, and failed frequency or keying operations restore the
  preceding correction, frequency, power, and key state.
- Changing the Si5351 reference correction invalidates its cached PLL plan so
  the next frequency update always programs parameters calculated from the new
  correction.
- The EEPROM layout migrates the former reserved calibration slot without
  moving existing settings or the session-history journal. New host tests cover
  parsing, correction arithmetic, persistence ordering, rollback, carrier
  entry/exit, and button-exit behavior.
