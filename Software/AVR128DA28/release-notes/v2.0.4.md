# SignalSlinger 2.0.4

SignalSlinger 2.0.4 is the next firmware release after v2.0.3.

## User-visible changes

- Thermal shutdown is enabled by default at 65 C, including on older devices without a saved choice. Temperature reporting, maximum-temperature tracking, and fan control remain active.
- Operators can explicitly disable or enable thermal shutdown and select a trip threshold from 30 C through 85 C in a compatible SerialSlinger build.

## Stability and reliability

- The configured threshold is now the actual trip point for every battery configuration, with a uniform 5 C clear hysteresis.
- The enable choice uses the existing EEPROM padding byte, preserving all established configuration offsets and migrating legacy, erased, or unknown values to enabled at 65 C. Explicit choices saved by this firmware remain in effect.

- An overheated scheduled session pauses with RF off and resumes in its original time window after cooling by 5 C. Cooling does not extend the finish time or consume a later day.
- Later scheduled days survive a thermal interruption. Remaining days describe calendar windows, not successful runs.
- EVT reports device-recorded starts, pauses, resumes and stops, including reason, device time (when known), temperature and threshold. A bounded EEPROM journal retains recent history across resets and rejects incomplete writes.
- A finish after a pause is reported as interrupted or finished with interruptions, never uninterrupted completion. Power loss/reset is recorded with an unknown stop time rather than an invented timestamp.
- Missing or stale temperature readings block RF until a valid safe reading arrives. Manual starts remain subject to the same RF protection.

## Installation and field testing

Use SerialSlinger 2.0.20 for the matching session-history display and delayed multi-day schedule fixes. In SerialSlinger, select the firmware update for the transmitter hardware revision (HW 3.4 or HW 3.5). The matching ZIP includes the recovery files and programming instructions; read its README before recovery or first-install programming.

After updating, reconnect and confirm firmware 2.0.4, temperature protection enabled, and a 65 C shutdown threshold. Read back the requested start date, daily finish time, and three scheduled days. Thermal recovery preserves the original finish time; it does not add extra operating time after cooling. Save SerialSlinger session logs after the field test.

Automated checks cover thermal recovery, scheduling, EEPROM history, and both hardware builds. Physical programming, RF output, temperature response, and recovery on representative HW 3.4 and HW 3.5 units remain unverified for this candidate.
