# SignalSlinger 2.0.3

SignalSlinger 2.0.3 adds a stable device identity for safer transmitter
management and strengthens the firmware release process for both supported
hardware revisions.

## User-visible changes

- The firmware now reports the AVR's factory-programmed device ID as a
  32-character `uid` value in `INF` status output. The ID remains stable across
  firmware updates and settings changes, allowing compatible tools such as
  SerialSlinger to recognize when a different transmitter is connected through
  the same USB serial adapter. Older firmware remains compatible and simply
  omits this line.
- The project README now links directly to the available SignalSlinger
  transmitter kit and its current ordering information.

## Stability and reliability

- Stable device identity improves update target verification and reduces the
  risk of silently treating a replacement transmitter as the previously loaded
  unit.
- Release builds for HW-3.4 and HW-3.5 now use pinned compiler and device-pack
  versions on macOS, with byte-for-byte repeatability checks for the normal
  application, bootloader-relocated application, bootloader, and complete
  release packages. Package contents, checksums, flash geometry, compiler
  warnings, and source revision are independently validated before
  publication.
- Bootloader behavior and its protocol are unchanged in this release.
