# SignalSlinger 2.0.5

SignalSlinger 2.0.5 corrects temperature and voltage sampling and improves external-battery feedback while the unit is awake. Packages are available for HW 3.4 and HW 3.5.

## User-visible changes

- Temperature queries now allow the sensor and ADC to settle correctly. This fixes falsely elevated readings during repeated SerialSlinger refreshes and the resulting fan stopping and restarting every few seconds.
- External-battery LED feedback updates more promptly while the unit is awake. Brief voltage checks detect a connected battery when managed external power is off; an intentionally disabled power output no longer replaces the last measured battery voltage with zero.
- The existing sleep schedule, fan temperature thresholds, and thermal-protection settings are preserved.

## Stability and reliability

- All five supported ADC inputs use the corrected channel-selection and startup sequence, including the first measurement after charging or standby initialization.
- Foreground temperature and voltage readings share one conversion helper. It clears stale completion flags, bounds the wait for a fresh result, and shuts the ADC down on timeout so later measurements can recover.
- Regression checks cover channel changes, pre-enabled startup, stale results, completion at the timeout boundary, stalled conversions, recovery, and free-running to single-shot transitions. Battery-feedback checks retain the sleep and shared-output boundaries.

### Hardware validation scope

The ADC corrections were programmed and checked on a HW 3.5 unit, including live temperature and battery readings; the reported fan cycling stopped. Those checks used the development build preceding the release version change. Full physical HW 3.4 validation, interrupted-update recovery, and hardware rollback have not been completed for this release.
