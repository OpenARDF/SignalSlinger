# SignalSlinger 2.1.0

SignalSlinger 2.1.0 adds persistent hardware-fault reporting and migrates the
EEPROM to a compact, explicitly bounded layout that preserves existing settings
and session history while reserving space for future firmware data.

## User-visible changes

- Startup RTC and transmitter failures are retained in EEPROM instead of being
  visible only during the current power cycle. `HWF` lists the retained fault
  type and detection time when the clock was valid; `HWF C` deliberately clears
  the fault history.
- The hardware-fault journal retains the eight newest records across resets.
  Existing serial commands remain compatible, and an empty history reports its
  capacity without changing device state.
- Updating a legacy device migrates its configured event, fox role, callsign,
  patterns, frequencies, battery and thermal settings, schedule, calibration,
  and existing session history into the compact v2 EEPROM layout.

## Stability and reliability

- Settings, the seven-record session journal, and the new eight-record hardware
  fault journal occupy fixed, non-overlapping EEPROM regions. Compile-time
  assertions prevent later firmware changes from silently moving established
  settings or overrunning the 512-byte device EEPROM.
- Migration reads all legacy data before the overlapping rewrite, invalidates
  the layout marker during the operation, validates journal checksums, and
  commits the new marker last. An interrupted migration cannot be accepted as a
  valid partial layout; the host application's pre-update backup remains the
  recovery path.
- Host regression tests cover legacy migration, region boundaries, fault
  detection wiring, first-fault recording, journal rotation, CRC rejection,
  power-cut points, and isolation between fault clearing, settings, and session
  history. A live HW-3.4 update from 2.0.7 to 2.1.0 preserved the configured
  four-day Foxoring schedule, frequency banks, callsign, patterns, calibration,
  thermal settings, and existing session records; the updated unit reported
  firmware 2.1.0 and bootloader BL0.13.
